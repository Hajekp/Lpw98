Voice commands
"next" / "skip"Go to the next field "back"Go to the previous field "go to finish"Jump to a field (headset, episodes, size, hours, start, finish) "headset 12"Open headset 12's saved row to edit it, or start a new row for it "clear"Erase the current field "save" / "new row"Save this headset and start the next "read back"Hear the whole current row "undo"Delete the last saved row "stop listening"Turn the mic off

Every value you say is read back to you. Saying a new value replaces the old one. Saying a headset number that's already saved today opens that row. Upload duration and throughput are calculated automatically once upload start and finish are both filled in. Saying "next" on Upload finish saves the row.
